Recursos por namespace y aplicación

Todos generados por plantillas Helm (ningún manifiesto directo). Nombres efectivos: <repo>-deployment / -svc / -ingress / -env-file / -hpa en sis-<rama>-ms.

📦 sis-<rama>-ms · app <repo>

Chart ms-template · valores vía envsubst (GITHUB_*, ORG, IMAGE_TAG, MS_PATH) · ejemplo: repo devsu-demo-devops-java, rama test, path /api/users

IngressRoute plantilla

ingress.yaml · traefik.io/v1alpha1
  • entryPoint web, match Host(host) && PathPrefix(path)
  • destino <repo>-svc:80 (puerto 80 literal en la plantilla)

Service ClusterIP plantilla

svc.yaml
  • selector app=<repo>, port 80 → targetPort 8000 (valores templados)

Deployment + Pods plantilla

deployment.yaml · if enabled (true)
  • replicas 2, imagen ${ORG}/${REPO}:${TAG} Always, puerto 8000
  • resources 0.5/250Mi → 1/500Mi; liveness+readiness httpGet <path>:8000

HPA plantilla

autoscaling.yaml · autoscaling/v2 · kind: HorizontalPodAutoscaler
  • objetivo Deployment <repo>-deployment, min 2 / max 4, CPU 60%, estabilización 10s

ConfigMap sin consumidor confirmado

configmap.yaml · <repo>-env-file
  • data generada de fichero .env (no existe en el repo → contenido no confirmable)
  • El Deployment no lo monta ni lo referencia: relación omitida

Secret (referencia) condicional · inactivo por defecto

secret.enabled=false
  • Solo envFrom.secretRef:<repo> si se activa; no hay manifiesto Secret ni valores
